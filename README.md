- **Projects:** [Multilingual Phrasebook](https://github.com/Aslisho/multilingual-phrasebook), [Central Asia Currency Converter](https://github.com/Aslisho/currency-converter) and more

## Built with

HTML, CSS and a little JavaScript in a single `index.html`, hosted on GitHub Pages. No frameworks, no build step.

## Run it locally

```bash
git clone https://github.com/Aslisho/portfolio.git
cd portfolio
open index.html
```
